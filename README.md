## 🚀 About This Repository

This repository contains my solutions to the **GeeksforGeeks Problem of the Day (POTD)** challenge — a 60-day streak of solving daily algorithmic problems, spanning a wide range of Data Structures and Algorithms topics.

The challenge was hosted by **GeeksforGeeks** in collaboration with **NPCI (National Payments Corporation of India)**, promoting coding culture and consistency among developers across India.

## 📁 Repository Structure

```
GFG_POTD/
├── Day_01/
│   ├── solution.cpp   (or .py / .java)
│   └── README.md      # Problem statement + approach
├── Day_02/
│   ├── solution.cpp
│   └── README.md

    ├── solution.cpp
```

> Each folder contains the problem solution along with a brief note on the approach used.

## 💡 How to Use

```bash
# Clone this repository
git clone https://github.com/Niladri962/GFG_POTD.git

# Navigate to a specific day
cd GFG_POTD/Day_01

# Compile and run (C++ example)
g++ solution.cpp -o solution && ./solution
```
